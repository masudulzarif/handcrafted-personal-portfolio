# Handcrafted Personal Portfolio

A clean, responsive, and minimalist personal portfolio built with modern web technologies, designed with a zero-bloat philosophy.

## 🚀 Features
* **Minimalist Design:** Clean user interface focused on content readability.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.
* **Performance Focused:** Lightweight structure ensuring fast loading times.

## 🛠️ Tech Stack
* **HTML5 / CSS3**
* **TypeScript & JavaScript**
* **Vite**

## 📂 Project Structure
* `src/` - Contains the source code and components.
* `public/` - Static assets and files.
